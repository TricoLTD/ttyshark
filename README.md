# TricoLTD/ttyshark : a serial capture and analysis application
Usage:
- ttyshark [--help | -h]
- ttyshark [--capture | -c] <serial_device> <capture_location [default is ./cap_Y-M-D-H-M-S.bin]> : capture of a serial device specification is order sensitive.
- ttyshark [--analyze | -a] <capture_location> : analyze the capture bin dump
